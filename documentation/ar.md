# مؤشر Nottingham للإنذار (NPI)

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/indice-prognostico-de-nottingham)

## كيفية الاستخدام

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### أكبر قطر للورم الغازي (المرضيات)

`tam`

cm · النطاق: ٠٫١–٢٠

### العقد اللمفاوية الإبطية

`lnd`

- `1` — سلبية
- `2` — ١ إلى ٣ إيجابية
- `3` — ٤ إيجابية أو أكثر

### الدرجة النسيجية (Nottingham/Elston-Ellis)

`grau`

- `1` — الدرجة ١
- `2` — الدرجة ٢
- `3` — الدرجة ٣

## إصدار الطريقة

NPI/هيبيتل 1982/غاليا 1992: 0.2 حجم cm+مرحلة العقد 1–3+درجة 1–3

## المعادلة الموثقة

NPI = 0.2 × الحجم (cm) + مرحلة العقد (1–3) + الدرجة النسيجية (1–3).

مرحلة العقد: 1=لا عقد مصابة؛ 2=1–3 عقد؛ 3=4 فأكثر (والأصل يشمل قمة الإبط أو العقد الثديية الداخلية).

## الحدود والفئة السكانية

يربط NPI الخصائص التشريحية المرضية لسرطان الثدي الأولي بالإنذار. يتطلب المجموع تحديد مرحلة العقد اللمفاوية والدرجة على نحو صحيح؛ ولا يحدد العلاج الحالي، ولا يضمن البقاء الفردي. يجب أن تتطابق المعادلة والمجموعات والمعدلات مع الإصدار والفئة السكانية المستخدمين.

```sh
node test.cjs
```

لم تُجرَ مراجعة سريرية مستقلة.

هذه الواجهة ترجمة أعدّها مؤلفوها، وليست إصدارًا رسميًا أو معتمدًا. لم تُجرَ مراجعة سريرية مستقلة أو مراجعة لغوية مهنية، ولم تُستكمل الموافقة على حقوق استخدام الأدوات.
